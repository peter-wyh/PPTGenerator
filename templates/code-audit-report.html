🔴 Critical（3 项 — 立即修复）
C-1 安全
生产环境使用弱默认 JWT 密钥 — 可伪造任意用户 Token
apps/server/src/config.ts:34-35 · .env.prod:5-6

config.ts 中 JWT 密钥在环境变量缺失时静默回退到 'dev-access-secret-change-me'。而 .env.prod 声明 NODE_ENV=production，却使用了这个公开默认值。任何人知道此值即可伪造 access/refresh token，完全绕过认证。

JWT_ACCESS_SECRET=dev-access-secret-change-me ← .env.prod 第5行
修复：① 生产环境 config.ts 强制要求密钥（无回退值，缺失即 throw）；② .env.prod 替换为 ≥32 字节随机密钥（openssl rand -hex 32）。
C-2 Bug
导出服务缺少 await — PDF/图片导出功能完全失效
apps/server/src/modules/export/export.service.ts:101, 116

ensureShareToken() 返回 Promise，但调用处缺少 await。模板字符串拼接后 token 变为 "[object Promise]"，puppeteer 访问的 URL 永远是错误的 → 所有导出请求返回 404。

const token = ensureShareToken(ownerId, projectId); // ← 缺少 await const shareUrl = `${config.webUrl}/share/${token}?print=1`; // → ".../[object Promise]"
修复：添加 await — const token = await ensureShareToken(ownerId, projectId);（两处：exportProjectPdf L101 + exportProjectImages L116）。

CampaignCollabPage.tsx — 1457 行 God Component，最复杂函数 ~200 行
apps/web/src/routes/CampaignCollabPage.tsx

单文件包含 1 主组件 + 6 内联子组件 + 3 工具函数。核心函数 confirmCollabImport（L236-440+）约 200 行，含两轮遍历 + 嵌套 Map + 6 层缩进。DeliverableCard（L863-1413）550 行、4 个 return JSX 块。

拆分建议：

  • CampaignCollabPage/（主页面壳）
  • CollabDrawer.tsx（抽屉组件）
  • DeliverableCard.tsx（交付物卡片）
  • collabImport.ts（导入逻辑）+ collabMetrics.ts（聚合工具）

M-2 安全
SVG 上传可导致存储型 XSS
apps/server/src/modules/upload/upload.routes.ts:13-16

MIME 检查仅基于客户端 Content-Type（可伪造），image/svg+xml 在允许列表中。SVG 可内嵌 <script>，通过 express.static 以原始 Content-Type 返回 → 浏览器执行 JS。

campaigns.service.ts · data.service.ts:90-119

importMany 每条记录先 findUnique 再 update/create，全部串行 await。N 条记录 = 2N 次数据库往返。

改用 prisma.$transaction([...]) 或 createMany({ skipDuplicates: true })。
